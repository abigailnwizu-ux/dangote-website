# Dangote Website Clone

A partial front-end clone of the Dangote Group website homepage, built with HTML and CSS as a mentor-assigned practice exercise.

## What it does

Recreates the layout and styling of select sections of the Dangote Group homepage, focusing on replicating structure, spacing, and visual design using only HTML and CSS.

## Tech Stack

- **HTML5**
- **CSS3**

## About this project

This was a solo exercise assigned by my mentor to practice translating a real, professional website's design into clean HTML/CSS. It's a partial clone — covering the homepage and a few key sections rather than the full site — and was built from scratch by hand-coding markup and styles to match the original layout.

## What I learned

- Structuring semantic HTML for a real-world, content-heavy layout
- Writing CSS to replicate spacing, typography, and responsive sections
- Attention to detail when matching an existing design

## Status

This is a learning/practice project, not an original design and not affiliated with Dangote Group.
